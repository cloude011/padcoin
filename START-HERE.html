PADCOIN / SELF-HOSTING KIT

Another day.
Another launchpad.

Your animated site is included in this folder. It has 53 launchpads, filters, search, saved roasts, sharing, submissions and voting. Start with either method below.

Option 1: deploy from your computer

  1. Extract the ZIP. Open the padcoin folder.
  2. Install Node.js 22 if needed.
  3. Windows: double-click deploy.cmd. Mac/Linux: open Terminal in this folder and run bash deploy.sh. You can also run this command directly:
    npx --yes vercel --prod
  4. Follow the sign-in prompts, choose your Vercel account/team, create a new project named padcoin, and use this directory as the project root. Framework and build settings are already configured.

Option 2: upload through GitHub

  1. Create a GitHub repository and upload the contents of this folder. Keep package.json, vercel.json, and app at the repository root.
  2. Open vercel.com/new, import the repository, and deploy it as a Next.js project.

Make shared votes and submissions work

The site needs a persistent database for community activity. After creating the Vercel project:

  1. In Vercel, open your project’s Storage area and add Turso Cloud. Choose its free option if available and connect it to your project.
  2. Ensure the project has TURSO_DATABASE_URL and TURSO_AUTH_TOKEN for Production (and Preview if you use it). The integration supplies these; keep the token private.
  3. Redeploy from Vercel or run the deploy command again. Tables are created automatically when the board first loads.

Until storage is connected, the roster, animations, search and saved roasts work; shared votes and new submissions show a sync error.

Optional custom domain

Add your domain in Vercel’s project settings. For social previews, set NEXT_PUBLIC_SITE_URL to its full HTTPS address and redeploy.

What is included

The working source and all visual assets. Opening app/page.tsx is for editing; the actual site must run through Next.js or Vercel. This guide itself opens locally.

Existing community activity from the earlier hosting database is not bundled. The new database starts empty. The previous revert is preserved: Clank appears as one separate launchpad entry.

Verified: production build, type checks, search/filter behavior, persistent submission and vote logic, vote removal and submission limits.
